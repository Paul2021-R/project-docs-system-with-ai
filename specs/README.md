# Specs — 기획 및 설계 원본 명세서

본 디렉토리는 인간(Human)이 작성하고 제공한 최종 확정 기획서, 요구사항 명세서, DB 스키마 정의, API 명세서 원본(TSV 등)을 보관하는 공간이다.

## 폴더 규칙 및 역할

1. **Ground Truth (최우선 참조 기준)**: 
   - 이 디렉토리의 파일들은 모든 비즈니스 요구사항 및 구현의 최종 기준이다.
   - AI(Gemini/Claude)는 작업을 시작하기 전 본 디렉토리의 도메인 관련 기획 문서를 최우선적으로 정독해야 한다.
   
2. **AI 임의 수정 금지**:
   - AI는 이 디렉토리 하위의 핵심 명세서를 임의로 편집하거나 왜곡하여 수정할 수 없다. 기획 변경은 오직 Human의 지시와 승인을 통해서만 반영된다.
   
3. **아카이빙 및 파일 정리**:
   - 현재 유효한 핵심 기획 및 명세 파일만 `specs/` 루트에 깔끔하게 유지한다.
   - 오래된 감사 리포트, 임시 분석 결과 등 명세서 성격이 아닌 보관용 파일은 `specs/archive/` 하위 폴더로 격리한다.
