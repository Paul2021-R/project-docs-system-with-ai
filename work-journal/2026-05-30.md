## 3. Git LFS 설치 및 적용

`git lfs`가 git 내장이 아니라 별도 바이너리라, 패키지 설치가 선행되어야 한다.

```fish
sudo pacman -S git-lfs
git lfs install
```

무거운 바이너리 에셋을 LFS로 추적 설정한다.

```fish
git lfs track "*.mp4"
git lfs track "*.mov"
git lfs track "*.wav"
git lfs track "*.ogg"
```

### 결과

- `git-lfs` 설치 + `git lfs install` 완료 [o]
- `.gitattributes`에 영상·오디오 확장자 LFS 추적 규칙 등록 [o]
