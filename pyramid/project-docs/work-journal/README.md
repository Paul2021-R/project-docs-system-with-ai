# work-journal — 역할별 날짜 단위 저널

```
work-journal/{YYYY}/{MM}/{YYYYMMDD}-{역할}.md
```

- 역할마다 자기 파일만 쓴다. 같은 날 같은 역할의 작업은 같은 파일에 절을 덧붙인다.
- **쓰는 시점**: 맡은 지시 하나를 끝낼 때 — 완료 · 개선 이관 · 막힘 보고.
- 이미 쓴 `##` 절은 고치지 않는다. `## 미완 / 다음`만 갱신할 수 있다.
- 개선 역할은 진단 결론만 쓰고 상세는 `handoff/strikes/` 파일을 링크로 가리킨다.

```markdown
# 2026-10-22 · lead-server

## 미완 / 다음
- {{SLUG_UPPER}}-12 work-review 대기

## 1. {{SLUG_UPPER}}-12 설계 완료
**결론**: 태그 후보 검색은 연결 테이블 인덱스로 간다.
근거 · 트레이드오프 · 남긴 파일 경로.
```

커밋한 뒤 저널을 갱신하지 않고 세션을 끝내려 하면 Stop 훅(`scripts/journal-gate.sh`)이 막는다.
